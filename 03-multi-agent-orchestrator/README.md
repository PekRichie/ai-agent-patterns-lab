# Többágenses Koordinátor (Planner → Builder → Reviewer)

## Miért értékes ez éles AI rendszerekben?
Szereposztásos többágenses végrehajtási csővezeték automatikus felülvizsgálati körrel és újrapróbálással (Kaptár minta).

## Fájlok
- `app.py` — tiszta, függőségmentes Python 3 referencia-implementáció
- `test_app.py` — automatikus `unittest` tesztkészlet

## Futtatás
```bash
python3 -m unittest test_app.py -v
```

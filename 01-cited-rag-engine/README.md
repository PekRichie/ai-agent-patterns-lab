# Hivatkozásos RAG Motor (Chunking + Hybrid Retrieval + Citation Check)

## Miért értékes ez éles AI rendszerekben?
Dokumentumok darabolása átfedéssel, BM25-alapú keresés és forráshivatkozásos válaszgenerálás hallucináció-ellenőrzéssel.

## Fájlok
- `app.py` — tiszta, függőségmentes Python 3 referencia-implementáció
- `test_app.py` — automatikus `unittest` tesztkészlet

## Futtatás
```bash
python3 -m unittest test_app.py -v
```
